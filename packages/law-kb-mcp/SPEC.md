# 法律知识库 MCP — 规范文档

## 一、定位与目标

为法律工作场景提供离线可用的法律检索能力：

- **离线优先**：知识库在打包时预置，用户端无需网络、无需下载模型
- **语义检索**：FTS5 关键词检索 + 向量检索双路融合（RRF），支持模糊语义查询
- **权威来源**：仅收录全国人大官网（flk.npc.gov.cn）、最高人民法院（court.gov.cn）的公开数据
- **可增量更新**：用户可通过 `sync_laws` 工具在线补充最新法规

## 三、数据格式规范

### 3.1 法律条文（laws 表）

```
title          法律名称（如"中华人民共和国民法典"）
category       类别（民法、劳动法、刑法……）
article_number 条文编号（如"第七百零三条"）
content        条文全文
effective_date 施行日期
source_url     来源 URL
```

### 3.2 指导案例（laws 表，category = "指导案例"）

```
title          "指导案例 NNN 号：案由"
content        裁判要点 + 基本案情 + 裁判理由（合并为文本）
category       "指导案例"
effective_date 发布日期
source_url     原文链接
```

### 3.3 分块规则（chunker.ts）

| 内容类型 | 分块策略 |
|---------|---------|
| 法律条文 | 每条单独一 chunk；超过 512 token 的条文按句切分，保留条号前缀 |
| 司法解释 | 同法律条文 |
| 指导案例 | 裁判要点单独一 chunk；基本案情 + 裁判理由合并，超长则滑窗切分（stride 50%）|

## 四、向量化规范

### 4.1 模型

| 项目 | 值 |
|------|----|
| 模型 | `BAAI/bge-small-zh-v1.5` |
| 维度 | 512 |
| 量化 | int8（quantized=true） |
| 磁盘大小 | ~130MB |
| 来源 | HuggingFace / hf-mirror.com |

选型理由：bge-m3（1GB）过大不适合打包；bge-small-zh 中文语义效果在法律场景经测试足够，且体积可接受。

### 4.2 嵌入策略

- **构建期**：seed 脚本在开发者机器上完成全量嵌入，结果写入 DB
- **运行期**：用户端不下载模型，直接读取预置 embedding 做向量检索
- **增量**：用户通过 `sync_laws` 添加新法规时，若模型不在本地则仅做 FTS 检索（降级）

### 4.3 检索策略（search.ts）

```
query
  ├── FTS5 关键词检索（top-10 chunks）
  └── 向量余弦检索（top-10 chunks）
        ↓
      RRF 融合排序（k=60）
        ↓
      返回 top-K 结果（默认 K=5）
```

## 五、构建流程

```
开发者执行：node scripts/seed-law-db.mjs
  1. 检查 model 是否已下载，没有则自动下载 bge-small-zh
  2. 按优先级爬取法律条文（P0 → P1）
  3. 爬取司法解释
  4. 爬取最高院指导案例
  5. 分块 → 嵌入 → 写入 laws.db
  6. 打印统计报告（法律数、条文数、chunk 数、向量数）

输出：packages/law-kb-mcp/data/laws.db
      packages/law-kb-mcp/data/model/（bge-small-zh，.gitignore）

打包时：
  - laws.db → extraResource（mcp-servers/laws.db）
  - model 不打包（运行期纯用预置 embedding，不再加载模型）
```

## 六、运行期行为

| 场景 | 行为 |
|------|------|
| 首次启动（预置 DB） | 直接可用，向量检索正常 |
| 用户调用 `search_law` | FTS + 向量双路检索，RRF 融合 |
| 用户调用 `sync_laws` | 在线爬取最新法规，仅 FTS（无本地模型则降级）|
| 用户调用 `list_laws` | 返回库中法律目录 |
| 用户导入自定义文档 | 同 sync_laws 降级策略 |

## 七、不在范围内

- 裁判文书网（wenshu.court.gov.cn）的海量判决文书 —— 数据量过大（亿级），需要单独工程
- 地方性法规 —— 暂不收录
- 港澳台法律 —— 暂不收录
- 实时法规推送 / 变更监控 —— 暂不收录
